# Superpowers Suite

This skill provides an umbrella index to the Obra Superpowers method:

1. **`brainstorming`**: Use before any creative work or feature inception.
2. **`writing-plans`**: Spec & requirements breakdown into bite-sized tasks before touching code.
3. **`executing-plans`**: Step-by-step rigorous plan execution with verification.
4. **`subagent-driven-development`**: Parallel dispatch of isolated tasks.
5. **`test-driven-development`**: TDD loop before writing production code.
6. **`systematic-debugging`**: Root-cause analysis before speculative fixes.
7. **`verification-before-completion`**: Proof of passing tests and manual inspection before declaring victory.
8. **`using-superpowers`**: Session bootstrap and skill router.
